# TANGO-CHO2 学習通知

毎日 **8:45 と 18:15（日本時間）** に、アプリを閉じていても届く Web Push を配信します。通知をタップすると「通勤練習」を開きます。

**このコードを置くだけでは通知は有効になりません。** Cloudflareへ一度デプロイし、スマホで通知を許可してください。通信・OSの省電力制御・配信処理によって時刻が前後する場合があります。

## PCで一度だけ準備

Cloudflareにログイン済みのPCで、リポジトリのこのフォルダから実行します。

```bash
npm ci
npm run setup
```

未ログインの場合は `npx wrangler login` を先に実行してください。複数アカウントがある場合は利用するアカウントを選んでください。

セットアップは専用D1（`tangocho2-notifications`）を作成または再利用し、通知用の鍵を生成し、Workerと秘密鍵をデプロイします。元の単語帳の内容やOpenAI APIキーは送信しません。通知先と管理用トークンのハッシュだけを専用DBに保存します。

生成した `.keys.json` と `wrangler.json` はGitへ追加しません。再実行時も同じ鍵を再利用するため、このフォルダはPCに残してください。鍵を作り直した場合は、スマホ側で通知を解除してから再登録してください。

## スマホで設定

1. TANGO-CHO2を開き、「通勤練習 → 学習通知 → 初回設定」へ進みます。
2. デプロイ時に表示された `https://tangocho2-notifications.…workers.dev` を「配信先URL」に貼り付け、「接続」を押します。
3. 「通知を有効にする」を押し、スマホの通知を許可します。
4. 「テスト通知」で受信を確認します。

iPhoneでは先にホーム画面へ追加し、そのアイコンから起動してください。AndroidではChromeを利用できます。通知が届かない場合はOSの通知設定と省電力設定を確認してください。通知を停止するには「通知を解除」を押します。

## 配信と管理

- UTCの `23:45` / `09:15` にCronを実行し、日本時間の8:45 / 18:15に対応します。
- DBの原子的な更新で同じ配信枠の重複送信を防ぎます。期限切れの通知先は削除します。
- 通知先の登録解除とテスト送信には、登録した端末の管理トークンが必要です。
- 公開元は `https://masato-nasu.github.io` に限定しています。公開先のドメインを変える場合は、`wrangler.json` の `ALLOWED_ORIGIN` も変更して再デプロイしてください。
- 通知の有効期限は30分です。オフラインの間に期限を過ぎるとその通知は届かず、次回の練習時刻に配信します。
- 配信サーバーの公開後、実端末での「テスト通知」受信まで確認して設定完了です。

## 開発確認

```bash
npm test
npm run check
```

`check` は通信せずにソースの構文を確認します。`setup` はCloudflareへ変更を書き込みます。
